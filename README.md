# WebCraft BD — Agency & Web Development Marketing Website

আপনার নিজের ওয়েবসাইট বিক্রয় ও মার্কেটিং করার জন্য সম্পূর্ণ বাংলায় তৈরি আধুনিক React + Tailwind CSS ওয়েবসাইট।

## 📁 প্রজেক্ট লোকেশন:
`C:\Users\Admin\.gemini\antigravity\scratch\webcraft-agency`

---

## 🚀 লোকাল মেশিনে কীভাবে রান করবেন:
টার্মিনালে এই ফোল্ডারে গিয়ে কমান্ড দিন:
```bash
cd "C:\Users\Admin\.gemini\antigravity\scratch\webcraft-agency"
npm run dev
```
তারপর ব্রাউজারে `http://localhost:5173` ওপেন করলেই সাইটটি লাইভ দেখতে পাবেন!

## ⚙️ নাম, ফোন নম্বর ও তথ্য পরিবর্তন করার উপায়:
সবকিছু একটি সিঙ্গেল ফাইলে রাখা আছে যাতে আপনি কালকে নাম পছন্দ করার পর এক নিমিষেই পরিবর্তন করতে পারেন:
👉 ফাইল পাথ: `src/data/content.js`

* `brandName`: আপনার এজেন্সির নাম (যেমন: "StoreLaunch BD")
* `whatsapp`: আপনার হোয়াটসঅ্যাপ নম্বর (যেমন: "+8801700000000")
* `phone`: ডিসপ্লে ফোন নম্বর
* `email`: আপনার অফিসিয়াল ইমেইল
* `pricing`: যেকোনো প্যাকেজের মূল্য বাড়ানো বা কমানো
* `services` ও `demos`: নতুন ডেমো বা সার্ভিস যোগ করা
